# JudolGuard Blocklists

JudolGuard Blocklists adalah kumpulan daftar blokir (blocklists) yang berfokus pada pemblokiran situs judi online, iklan terkait perjudian, domain phishing, serta domain berbahaya lainnya.

## Fitur

* Blokir ribuan domain judi online.
* Pembaruan berkala.
* Kompatibel dengan AdGuard, AdGuard Home, Pi-hole, uBlock Origin, NextDNS, DNS sinkhole, dan aplikasi lain yang mendukung format hosts atau domain list.
* Dapat digunakan secara gratis untuk penggunaan pribadi maupun komersial.

## URL Blocklist

Salin URL berikut untuk digunakan pada aplikasi yang mendukung custom blocklist:

```text
https://raw.githubusercontent.com/evozifans/judolguard-blocklists/main/blocklist/judol-guard.txt
```

## Penggunaan

Tambahkan URL di atas ke aplikasi pemblokir konten atau DNS Anda, kemudian lakukan pembaruan (update) daftar blokir agar perubahan terbaru diterapkan.

## Kontribusi & Laporan

Jika Anda menemukan situs judi online yang belum terblokir, atau menemukan situs yang terblokir secara keliru (*false positive*), silakan kirim laporan melalui halaman di bawah ini.
